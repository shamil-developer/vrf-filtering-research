# Исследование фильтрации трафика в VRF-контурах

Исследовательский стенд для проверки и сравнения подходов к фильтрации сетевого трафика в VRF-контурах. Репозиторий содержит воспроизводимую среду для функционального тестирования, нагрузочных испытаний и подготовки архитектурных решений.

Цель репозитория:
- Проверить, как `nftables` правила применяются к интерфейсам типа `vrf` и `bridge`
- Замерить деградацию производительности (`iperf3` или иной инструмент) при наличии 1000+ правил
- Исслудовать выбор между `nftables` (проще в реализации) и `ebpf` (быстрее, но сложнее) (или вообще иной способ)
